🎓 Student Portfolio

A simple and interactive Student Portfolio Web App built using Python and Streamlit.

✨ Features

- 👤 Personal Information
- 🎓 Academic Information
- 🏫 College Name
- 📚 Course and Branch Selection
- 📖 Semester Selection
- 📊 CGPA
- 💻 Skills
- 🎯 Future Plans
- 🚀 Career Goals
- ✅ Submit Button to display entered information

🛠️ Technologies Used

- Python
- Streamlit

📂 Project Structure

My-Portfolio/
│
├── Portfolio.py
└── README.md

▶️ How to Run

First, install Streamlit:

pip install streamlit

Then run the application:

streamlit run Portfolio.py

The application will open in your web browser.

🎯 Purpose

This project is created as a simple student portfolio application to practice Python, Streamlit, user input, and basic web application development.
